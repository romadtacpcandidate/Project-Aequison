# Contributing to AEQUISON

AEQUISON research contributions should be reproducible, carefully sourced, and reviewed before publication.

1. Create an issue with the research question and related document ID.
2. Work on a feature branch such as `research/atmosphere-validation` or `docs/compliance-review`.
3. Include assumptions, references, version numbers, uncertainty, limitations and test results.
4. Submit a pull request for independent technical review.
5. Do not merge or publish unreviewed claims.

Never upload confidential team information, passwords, personal contact information, unpublished restricted files, sensitive hardware specifications, or third-party content without publication rights. Academic or partner-held ANSYS licenses require usage verification before competition-related work.

Track negative results and errors as rigorously as successful studies.

# AEQ-VER-001 — Research Verification & Validation
**Revision 0.1 · Draft · 2026-10-08**

## Distinctions
- **Verification:** Did we implement and solve the equations/method correctly?
- **Validation:** How well does the model represent independently observed physical data for its stated purpose?
- **Qualification:** Does a defined requirement have accepted evidence? Research verification does not imply aircraft or competition qualification.

## Minimum evidence package
| Field | Record |
|---|---|
| Requirement/hypothesis | Unique ID |
| Model/test case | Name, configuration and revision |
| Author/reviewer | Independent roles |
| Inputs | Sources, units, parameters |
| Software | Product, version, license scope |
| Reference | Publication, date, link |
| Verification | Unit checks, numerical/convergence tests |
| Validation | Independent measurement and uncertainty |
| Acceptance criteria | Defined before interpretation |
| Outcome | Pass, fail or inconclusive |
| Evidence | Immutable/controlled location |
| Release status | Private / Approved public |
